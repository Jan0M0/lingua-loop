# CURRICULUM · 课程地图与编排规则

数据源：`src/data/curriculum/en-weeks.ts`（24 周）、`es-weeks.ts`（24 周）、`recipes.ts`（30 天配方 + 周模式）。

## 英语（IELTS 8 导向，默认 Academic）

| 阶段 | 周次 | 主线 |
| --- | --- | --- |
| 基线建立 | 1–2 | 微诊断、词卡起步、阅读细节与定位 |
| 基础强化 | 3–7 | 听力关键词/数字、T2 结构、P1 流利、主旨与态度题、T1 入门 |
| 专项进阶 | 8–11 | 推断与同义替换、P2 话题卡、语法范围、听力态度与多步骤 |
| 期中检验 | 12 | 全真限时组合 + 12 周错题复盘 |
| 深度提升 | 13–17 | 论证深度、词汇精准度、限时阅读、速记、纠音 |
| 弱点歼灭 | 18 | 按个人掌握度数据定向加练 |
| 冲刺 | 19–21 | 全真组合、写作全真、口语全真模拟 |
| 考前 | 22–24 | 总复习、减量保持、轻激活 |

每周含：主题、重点技能、2–3 条具体目标、建议投入分钟、周末检查点（自查标准）、可选错误标签重点。

General Training 切换：设置中改考试类型后，写作 Task 1 自动优先安排书信任务，阅读训练保持不变（内容库中 T1 书信为原创情境）。

## 西语（A1 → B2 方向，起点按诊断修正）

| 阶段 | 周次 | 主线 |
| --- | --- | --- |
| A1 | 1–6 | 问候/数字时间/家庭食物/购物问路/现在时系统/生活场景任务 |
| A2 | 7–12 | indefinido、旅行叙事、imperfecto、将来计划、请求建议、A2 检验 |
| B1 | 13–18 | 观点表达、虚拟式场景、正式语域、长文本、正常语速听力、B1 检验 |
| B2 方向 | 19–24 | 复杂话题讨论、论证写作、新闻式输入、巩固与总结 |

语法按 20 课小课序列化引入（ser/estar → 现在时 → 反身/gustar → 宾格代词 → 双过去时 → 将来/条件 → por/para → 虚拟式高频场景 → 连接词 → 命令式等），只在对应周由调度器安排，不一次性灌输。

## 每日编排规则（引擎：src/engine/scheduler.ts）

1. **到期复习置顶**：SM-2 到期卡永远排在第一位（过期最久优先、lapses≥2 弱点卡加权），上限为时间预算的 40%。
2. **前 30 天**：按每日配方（30 个不同组合，EN/ES 混编，语言占比≈设置比例）。
3. **第 31 天起**：按星期模式（周一阅读/周二听力/周三写作/周四阅读/周五听说/周六写作语法/周日检查点）+ 当周主题，继续自动编排，没有"到期"。
4. **选材**：难度瞄准当前掌握度（+反馈偏移），7 天冷却避免短期重复，内容用尽时明确提示而不是假装生成。
5. **疲劳感知**：当天有"疲惫"反馈 → 低认知负荷任务优先。
6. **确定性**：同一天同一状态生成结果完全一致（种子=日期+盐+槽序），生成后持久化。

## 检查点与复盘

- 每日：全部任务完成后自动生成当日复盘（完成了什么/最常见错误/明天优先）。
- 每周：「进步」页周报对比时间、正确率、复习完成率、覆盖缺口，并给下周建议；样本不足（<15 事件）明确声明。
