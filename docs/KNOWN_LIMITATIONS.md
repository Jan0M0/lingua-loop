# KNOWN_LIMITATIONS · 已知限制（不夸大的部分）

## 评分与预测
- 掌握度 0–100 是内部趋势指标，**不是** IELTS Band、CEFR 等级或任何官方预测。样本不足时显示"数据不足"，并收缩到先验。
- 写作/口语没有自动评分。规则检查是启发式（字数/段落/句长/重复/连接词/常见混淆），不能替代考官；自评清单帮助自我校准。
- 微诊断只用于设定起步难度。

## 内容
- 内容库为原创、数量有限（见 README/内容库页统计）。调度器会用冷却与轮换延缓耗尽，但**不做不到"无限生成新题"**——用尽时明确提示。可用「内容库 → 导入 JSON」补充（未来可用任何 AI 生成 JSON 后导入，schema 见 docs/CONTENT_AUTHORING.md）。
- 听力为系统 TTS 朗读原创脚本：单说话人情境较自然；双说话人对话靠两种系统语音区分，不可用时退化为单语音朗读（不读说话人标签）。TTS 质量取决于操作系统。
- 浏览器 TTS 的语速/音色不可强控，西语低级别已设较慢语速提示，但实际效果因系统而异。

## 技术与平台
- 数据绑定在**当前浏览器 + 设备**。换设备/换浏览器需手动导出备份再导入（含录音的备份文件较大）。
- 隐私/无痕模式可能禁用 IndexedDB —— 应用会显示明确错误而不是崩溃。
- 录音格式为 webm（视浏览器而定），Safari 兼容性未验证。
- Service Worker 仅在生产构建注册；PWA 安装在部分桌面浏览器可能不可用（不影响网页使用）。
- 断网使用的前提是至少完成过一次在线（或本地静态服务）加载。

## 学习法
- "IELTS 8 + 西语 B2 双目标 6 个月"是高挑战目标，可行性取决于基础、有效时间与输出反馈质量。应用提供的是结构、节奏与真实数据，不承诺结果；写作口语强烈建议周期性找合格老师/考官校准。
- SRS 参数（SM-2 风格）为通用设置，未按个人遗忘曲线调参——反馈机制会部分补偿。
